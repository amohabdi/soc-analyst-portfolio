# A. Blue Team Introduction

## Module Overview

The Blue Team Introduction module introduces the defensive side of cybersecurity, focusing on the Blue Team and its core component, the Security Operations Centre (SOC).

This module covers the Junior Security Analyst role, SOC operations, and human- and system-related attack vectors.
