# SOC Analyst Portfolio

## Hi 👋 I'm Mohamed

Self-directed cybersecurity student focused on ethical and defensive security. I'm building this portfolio to document my progress through the SOC Level 1 path and to show the work I've done along the way.

## My Objectives

- Build a solid foundation in Blue Team and SOC operations
- Learn how Tier 1 analysts triage alerts and decide what to escalate
- Understand human and system attack vectors and how they're detected
- Document each room and project clearly so the work can be reviewed
- Work toward a Tier 1 SOC Analyst role
